Frequently Asked Questions

Is QuerySense open source?

Yes. The CLI, analyzer, all 31 detection rules, and the 14-pattern SQL rewrite engine are MIT-licensed. Cloud features (dashboard, team collaboration, compliance packs) are available in paid tiers.

Does QuerySense need access to my database?

No. Core analysis works entirely offline with EXPLAIN JSON output. Database connection is optional for enhanced analysis (index validation, statistics freshness) and the watch daemon. Your data never leaves your machine unless you use Cloud.

Will features get paywalled later?

No. We saw how Liquibase paywalled include and how Flyway paywalled rollbacks. Our core tools stay free. New detection rules, rewrite patterns, and CLI features go into the free tier. Cloud collaboration features are paid.

How does QuerySense compare to pganalyze or Datadog?

pganalyze ($149+/mo) and Datadog DBM (per-host pricing) are production monitoring dashboards. QuerySense is a pre-production prevention tool. They're complementary: QuerySense catches issues before deployment, they monitor after. But if you only have budget for one, QuerySense covers more ground per dollar.

Can I use QuerySense in air-gapped environments?

Yes. The CLI is fully offline. Install the package, analyze EXPLAIN output, get results. No network calls, no telemetry, no cloud dependency. EverSQL can't do this. Neither can most SaaS monitoring tools.

Do you have an API?

Yes. Full REST API at /api/v1/ with endpoints for analysis, SQL rewriting, plan comparison, and plan management. Stateless endpoints require no authentication. pgMustard users have been asking for this (GitHub issue #71) — we ship it by default.
