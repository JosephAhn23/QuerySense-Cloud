How to get BUFFERS data

EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON) SELECT * FROM orders WHERE status = 'pending';

The BUFFERS option shows per-node I/O: shared hit (cache), shared read (disk), dirtied, and written blocks. Each block = 8KB. A cache hit is ~100x faster than a disk read.
